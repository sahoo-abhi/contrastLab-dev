# contrastLab-dev

Minimal React + Vite UI for uploading a web app screenshot and viewing component-level WCAG checks.

## Quick Start

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Current UI Scope

- Screenshot upload with local preview
- Analyze action with mock processing state
- Sample component detection list
- Pass, warning, and fail WCAG status cards

Note: Component identification and compliance scoring are currently mocked in the UI layer.
